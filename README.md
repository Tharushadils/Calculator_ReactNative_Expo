# 🧮 React Native Calculator App

A lightweight and modern Calculator application built with **React Native** and **Expo** (SDK 57).

---

## 📱 Features

- **Basic Arithmetic Operations**: Addition, subtraction, multiplication, and division.
- **Clean UI**: Simple and intuitive design for fast calculations.
- **Cross-Platform**: Compatible with both Android and iOS devices.
- **Standalone APK**: Built and distributed via Expo Application Services (EAS).

---

## 🚀 Tech Stack

- **Framework**: [React Native](https://reactnative.dev/)
- **Platform**: [Expo SDK 57](https://docs.expo.dev/)
- **Build Tool**: [EAS Build](https://docs.expo.dev/build/introduction/)

---

## 🛠️ Prerequisites

Before getting started, make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo Go](https://expo.dev/go) app on your Android/iOS mobile device (for local development)
